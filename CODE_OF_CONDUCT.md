# Code of conduct

We want technical disagreement to produce better software without making the
project hostile to contributors.

Contributors and maintainers must:

- critique ideas and code, not people;
- state evidence, uncertainty, and tradeoffs plainly;
- respect privacy, attribution, and security constraints;
- avoid harassment, discrimination, threats, and unwanted personal contact;
- stop behavior when a maintainer says it is disruptive.

Report conduct concerns privately through the repository maintainers or a
private GitHub security advisory when confidentiality is required. Maintainers
may edit or remove contributions, restrict participation, or ban accounts when
needed to protect the project and its contributors.
